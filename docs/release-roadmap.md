# 증명 릴리스와 Continuous AI 재사용 계획

사용자 승인: 2026-11-10. 아래 순서로 작은 PR을 검증하고 반영한다.
최종 정리의 뜻과 공리 기준은 유지한다. Lean 주석은 명확하고 간결한 영어·수식으로 정리한다.

## 1. 재사용 가능한 Lean 라이브러리

- [ ] 일반 순열, 회전의 이웃 열거, 수축 사상, 순환 수열 API를 기초 모듈로 옮긴다.
- [ ] 중복 증명을 공통 정리로 대체하고 불필요한 가정·경고 억제를 검토한다.
- [ ] Lean 주석과 docstring을 영어로 정리하고 코드 토큰 불변 또는 명시한 API 변경을 확인한다.
- [ ] 모듈 안내와 Mathlib 기여 후보 목록을 만든다. upstream 제출은 별도의 사람 검토 과정이다.

## 2. Kuratowski 릴리스

- [ ] 공개 범위, 라이선스·저자·인용, 변경 기록과 사용 예제를 정리한다.
- [ ] 외부 Lake 소비 프로젝트에서 고정 버전으로 import와 최종 정리 적용을 확인한다.
- [ ] 전체 빌드, 새 공리 감사, import 목록, 블루프린트 웹·PDF·선언 검사와 유한 검사를 통과한다.
- [ ] 정확한 PR head의 CI와 독립 리뷰 뒤 릴리스 태그·산출물을 게시한다.

범위는 유한 단순 그래프의 조합적 평면성이다. 회전 체계와 위상적 매장의 대응은 이 릴리스에 포함하지 않는다.

## 3. Continuous AI 독립 패키지

- [ ] Kuratowski의 조사·검증·게시와 Smarandache–Wellin의 PR 보고·과제 큐에서 공통 기능을 추린다.
- [ ] 독립 저장소에 재사용 workflow, 버전 있는 설정, 시험, 설치·복구 문서를 묶는다.
- [ ] Lean 검사와 저장소별 머지 정책을 공통 코드와 분리한다.
- [ ] 두 저장소와 작은 비-Lean 예제에서 패키지 코드 수정 없이 설치·실행을 검증한다.
- [ ] 인증 값은 소비 저장소에 두고, 설치·갱신은 검토 가능한 PR로 제공한다.

## 4. gh-aw 비교

- [ ] 같은 입력·출력 계약의 조사 작업 하나를 gh-aw로 구성한다.
- [ ] 고정 버전 compile과 인증 준비를 확인한 뒤 제한된 수동 실행으로 비교한다.
- [ ] 유효한 결과, 검토 부담, 실패 복구, 유지할 코드와 비용 근거를 기록하고 구현을 선택한다.

일반 엔진 프레임워크나 새로운 workflow 언어를 만들지 않는다. 모델 추정 비용과 실제 청구액을 구분한다.
gh-aw 실행에 필요한 인증이 없으면 실행된 것처럼 보고하지 않는다.
